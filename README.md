# قواعد الإنجليزية خطوة بخطوة

موقع ثابت لدراسة ١٢٠ قاعدة بترتيب الكتاب، مع تمارين تُصحَّح فورًا.

## التشغيل
افتح `index.html` في المتصفح مباشرة (لا يحتاج خادمًا ولا إنترنت، عدا تحميل الخطوط).

## الملفات
```
index.html            الفهرس: ٢١ قسمًا و١٢٠ قاعدة، مع نتيجتك في كل قاعدة
unit.html             قالب صفحة القاعدة (unit.html#u4 يفتح القاعدة 4)
review.html           اختبار القسم: 20 سؤالًا مختلطًا من قواعد القسم (review.html#s0 للقسم الأول)
assets/style.css      التصميم
assets/app.js         العرض، التصحيح، حفظ التقدم
data/catalog.js       فهرس القواعد + قائمة القواعد الجاهزة + قواعد أولوية IELTS
data/units/u01.js …   محتوى القواعد الـ120 (نحو 1500 سؤال)
```

## طريقة الدراسة المقترحة
1. ادرس قاعدة واحدة أو اثنتين يوميًا، واقرأ الشرح قبل التمارين.
2. لا تنتقل حتى تحصل على 80٪ فأكثر، وأعد الأسئلة الخاطئة فقط.
3. في نهاية كل قسم اختبر نفسك من رابط «اختبار القسم»، وراجع القاعدة المكتوب رقمها بجانب أي سؤال أخطأت فيه.
4. ابدأ بالقواعد المميزة بنجمة إن كان موعد الاختبار قريبًا.

## إضافة قاعدة جديدة أو تعديلها
1. انسخ `data/units/u06.js` باسم جديد مثل `u07.js` وغيّر الرقم داخله `window.UNITS[7]`.
2. اكتب المحتوى في الحقول نفسها.
3. أضف الرقم إلى `window.AVAILABLE` في `data/catalog.js`.

### صيغة الحقول
- الألوان في الصيغة والأمثلة: `{s:الفاعل}` `{a:المساعد}` `{v:الفعل}` `{n:النفي}` `{q:أداة الاستفهام}` `{x:نص رمادي}`
- داخل الشرح العربي: ضع الإنجليزي بين علامتي `` ` `` و**الغامق** بين نجمتين.
- أنواع الأسئلة:
  - `mcq`: خيارات `o` ورقم الإجابة `a` (يبدأ من 0)
  - `fill`: أكمل الفراغ `___`، و`a` قائمة الإجابات المقبولة
  - `fix`: صحّح الخطأ، و`a` الجملة الصحيحة كاملة
  - `rewrite`: أعد الصياغة، مع `ask` لتوضيح المطلوب
  - كل سؤال يحتاج `why` لشرح الإجابة.

التصحيح يتجاهل الأحرف الكبيرة وعلامات الترقيم، ويعامل `doesn't` و`does not` و`doesnt` كإجابة واحدة.
