# قواعد الإنجليزية خطوة بخطوة

موقع ثابت لدراسة 120 قاعدة بترتيب الكتاب. كل درس شاشات قصيرة: فكرة واحدة في كل شاشة، مع سببها، ثم رسم أو مثال تتفاعل معه، ثم سؤال سريع. بعدها الأخطاء الشائعة، والتمارين سؤالًا سؤالًا، والخلاصة.

الموقع: https://yalhojaily.github.io/Ielts_prep/

## الملفات
```
index.html             الفهرس: 21 قسمًا و120 قاعدة، مع نتيجتك في كل قاعدة
unit.html              مشغّل الدروس (unit.html#u4 يفتح الدرس 4، و#u4-s3 الشاشة 3)
review.html            اختبار القسم: 20 سؤالًا مختلطًا (review.html#s0 للقسم الأول)
assets/site.css        التصميم (خط Cairo، ألوان لكل قسم، وضع ليلي)
assets/site.js         كل المنطق: الفهرس، الدروس، لبنات الشرح، الأسئلة، حفظ التقدم
data/catalog.js        فهرس الأقسام، الأسماء العربية، قواعد أولوية IELTS
data/units/u01.js …    محتوى كل قاعدة: الأخطاء الشائعة، التمارين (نحو 1500 سؤال)، نصيحة IELTS
data/lessons/l01.js …  شاشات الشرح لكل درس
```

التقدم يُحفظ في المتصفح (localStorage، المفتاح `grammar-progress-v1`).

## كتابة درس: data/lessons/lNN.js
```js
window.LESSONS[1] = {
  steps: [
    { k: "عنوان قصير في شريط الخطوات",
      h: "العنوان الكبير، و*نجمة واحدة* لتلوين كلمة",
      why: ["سطر يشرح المبدأ وسببه", "سطر ثانٍ"],   // يظهر قبل الرسم دائمًا
      show: [ { t: "timeline", ... } ],               // لبنة أو أكثر
      check: { q: "سؤال", o: ["خيار", "خيار"], a: 1, why: "لماذا" } }
  ],
  sum: [ { h: "عنوان", txt: "نص عربي", en: ["جملة"] } ]   // بطاقات الخلاصة
};
```
الشاشات الثابتة (الأخطاء، التمارين، الخلاصة، نصيحة IELTS) تُبنى تلقائيًا من ملف القاعدة.

### ألوان الجملة
`{s:فاعل}` `{v:فعل}` `{a:مساعد / be}` `{n:نفي}` `{q:أداة استفهام}` `{k:كلمة مهمة}` `{o:مفعول}` `{x:رمادي}` `{d:محذوف}`، و`{v:work|s}` يلوّن النهاية `s`.
داخل النص العربي: الإنجليزي بين `` ` ``، و`**غامق**`.

### اللبنات (t)
| النوع | الاستخدام |
|---|---|
| `timeline` | خط زمني: `marks` من نوع `dot`, `dots`, `band`, `wave`, `arrow`, `x` بمواضع من -1 إلى 1 (0 = الآن) |
| `build` | أزرار تغيّر الجملة: `opts: [[زر, جملة, ملاحظة, رقم المجموعة]]` و`groups` |
| `cards` | بطاقات بأيقونات |
| `compare` | أعمدة متجاورة للمقارنة (ويمكن أن تحتوي خطًا زمنيًا) |
| `formula` | صيغة الجملة بقطع ملونة |
| `map` | ربط بالأسهم (I → am) |
| `rules` | قواعد كتابة مع تجربة (s / es / ies) |
| `scale` | سلّم درجات، مع جملة تتغير أو ملاحظة لكل درجة |
| `decide` | سؤال قرار بفرعين |
| `trans` | تحويل جملة إلى أخرى |
| `chain` | خطوات متتابعة |
| `ex` · `fix` · `table` · `note` · `big` · `row` | أمثلة، خطأ ← صواب، جدول، ملاحظة، جملة كبيرة، لبنات متجاورة |

## أنواع الأسئلة (في data/units)
- `mcq`: خيارات `o` ورقم الإجابة `a` (يبدأ من 0)
- `fill` / `fix` / `rewrite`: `a` قائمة الإجابات المقبولة
- كل سؤال يحتاج `why`.

التصحيح يتجاهل الأحرف الكبيرة وعلامات الترقيم، ويعامل `doesn't` و`does not` كإجابة واحدة.
